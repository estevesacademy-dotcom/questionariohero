ANAMNESE H.E.R.O. - DEPLOY NA VERCEL

1. O QUE SUBIR

Suba para o GitHub ou arraste para a Vercel estes arquivos e pastas:

- index.html
- package.json
- vercel.json
- api/
- assets/

Este pacote nao depende mais de Netlify Forms nem de netlify/functions.

2. CONFIGURACAO DO PROJETO NA VERCEL

Ao importar o projeto na Vercel:

- Framework Preset: Other
- Root Directory: raiz do projeto
- Build Command: vazio
- Output Directory: vazio
- Install Command: vazio ou padrao

Depois clique em Deploy.

3. VARIAVEIS PARA ATIVAR A IA

Na Vercel, acesse:

Project Settings > Environment Variables

Crie:

OPENAI_API_KEY = sua chave da OpenAI

Opcional:

OPENAI_MODEL = gpt-5

Depois faca um novo deploy de producao. Variavel criada depois do deploy nao ativa no deploy antigo.

4. VARIAVEIS PARA RECEBER O FORMULARIO E AS FOTOS POR E-MAIL

A Vercel nao tem formularios nativos como a Netlify. O envio foi configurado por API e aceita duas opcoes:

OPCAO A - SEM DOMINIO PROPRIO, USANDO GMAIL/ICLOUD/OUTLOOK POR SMTP

Essa e a opcao mais simples quando voce nao quer comprar ou verificar dominio.

Para Gmail:

SMTP_SERVICE = Gmail
SMTP_USER = seuemail@gmail.com
SMTP_PASS = senha de app do Gmail
FORM_TO_EMAIL = marcosestevees@icloud.com
FORM_FROM_EMAIL = Consultoria H.E.R.O. <seuemail@gmail.com>

Para iCloud:

SMTP_HOST = smtp.mail.me.com
SMTP_PORT = 587
SMTP_SECURE = false
SMTP_USER = seuemail@icloud.com
SMTP_PASS = senha especifica de app da Apple
FORM_TO_EMAIL = marcosestevees@icloud.com
FORM_FROM_EMAIL = Consultoria H.E.R.O. <seuemail@icloud.com>

Para Outlook/Hotmail:

SMTP_SERVICE = Outlook365
SMTP_USER = seuemail@outlook.com
SMTP_PASS = sua senha de app ou senha autorizada
FORM_TO_EMAIL = marcosestevees@icloud.com
FORM_FROM_EMAIL = Consultoria H.E.R.O. <seuemail@outlook.com>

Depois faca um novo deploy.

OPCAO B - RESEND COM DOMINIO VERIFICADO

Crie uma conta em https://resend.com, gere uma API key e adicione na Vercel:

RESEND_API_KEY = sua chave do Resend
FORM_TO_EMAIL = marcosestevees@icloud.com
FORM_FROM_EMAIL = Consultoria H.E.R.O. <seu-email-verificado@seudominio.com>

Para producao, use um remetente com dominio verificado no Resend. Se o remetente nao estiver autorizado, o envio sera recusado pelo provedor.

5. COMO TESTAR

Depois do deploy:

- Abra https://SEU-SITE.vercel.app/api/generate-diagnosis
  Deve aparecer: {"error":"Metodo nao permitido."}

- Abra https://SEU-SITE.vercel.app/api/submit-form
  Deve aparecer: {"error":"Metodo nao permitido."}

Isso confirma que as APIs existem. Em seguida, preencha o formulario completo pelo dominio da Vercel, anexe fotos pequenas ou marque o envio posterior, finalize e confira o e-mail.

6. OBSERVACAO SOBRE FOTOS

As fotos sao comprimidas no navegador antes de irem para a IA e para o e-mail. Ainda assim, evite anexar imagens gigantes. Se o envio falhar por tamanho, reduza as imagens ou envie sem fotos e use a opcao de envio posterior.
